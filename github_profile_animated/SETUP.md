# Animated GitHub profile setup — gowripriya521

This package upgrades the profile README with GitHub-compatible animated SVGs/GIFs, typing text, a neon wave header/footer, skill icons, statistics cards, trophies, and the contribution-snake workflow. It keeps the existing profile banner/photo frame and the dark/light `<picture>` block for the snake. The React text is not included.

## 1. Upload files to your profile repository

Open https://github.com/gowripriya521/gowripriya521 and copy the files from this package into the repository root, preserving the folder structure:

- `README.md`
- `assets/profile-banner.svg`
- `assets/priya-frame.jpg`
- `.github/workflows/snake.yml`

Commit and push the changes to the default branch (usually `main`).

## 2. Enable the contribution snake

1. Open the repository's **Settings → Actions → General**.
2. Under **Workflow permissions**, choose **Read and write permissions** and save.
3. Open **Actions → Generate contribution snake → Run workflow**.
4. Wait for a successful run. The workflow publishes SVGs to the `output` branch.

## 3. Personalize your links and skills

- Replace the LinkedIn homepage link in `README.md` with your own LinkedIn profile URL.
- Edit the `currently_learning` list and technology icons to match skills you actually use.
- Pin your best repositories on the GitHub profile page. The featured-project section currently links to your repository list rather than claiming specific projects.

## Animation notes

- The typing text and wave banners are animated SVGs served by external services.
- The contribution snake is generated by GitHub Actions and appears after the first successful workflow run.
- GitHub README content cannot run arbitrary JavaScript or custom CSS, so browser-style hover transitions between arbitrary elements are not supported. The effects here use animated images/SVGs instead.
- External services can be rate-limited or temporarily unavailable. If a card does not load, try again later or remove that card.
