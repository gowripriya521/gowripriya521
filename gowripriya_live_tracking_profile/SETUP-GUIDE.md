# Setup guide — gowripriya521 profile

1. Extract the ZIP.
2. Upload all contents to the root of your public repository named `gowripriya521` (the profile repository name must match your username).
3. Include the hidden `.github/workflows/snake.yml` file and commit to `main`.
4. Open **Actions → Generate contribution snake → Run workflow**.
5. Check the `output` branch for generated SVGs, then refresh your profile page.

## Live counters and limitations
- The profile-view badge uses Komarev's public counter and updates as it receives views; external services can occasionally be delayed or unavailable.
- GitHub Stats cards fetch your public profile/repository data and refresh on their own cache schedule. New public repositories should appear after the stats service refreshes; it is not guaranteed to update instantly.
- GitHub does not provide a native profile “likes” counter. Stars are the closest standard public signal; the badge links to your GitHub stars view, but is not a live numerical star count.
- The avatar image loads from `https://github.com/gowripriya521.png`; changing your GitHub avatar updates it automatically.
- LinkedIn badge points to `https://www.linkedin.com/in/gaddamgowripriya`. If your actual LinkedIn URL differs, replace it in README.
- GitHub README cannot run arbitrary website JavaScript/CSS. SVG animations work where supported, but not every website transition can be replicated.
- Never upload passwords, API keys, or `.env` files.
