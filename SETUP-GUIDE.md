# Setup guide — video-style GitHub profile

1. Extract this ZIP.
2. Open the profile repository `gowripriya521/gowripriya521`.
3. Upload `README.md`, `assets/`, and `.github/workflows/snake.yml` to the repository root (keep folder structure).
4. Commit to `main`.
5. Open Actions → Generate contribution snake → Run workflow.
6. Confirm `output` branch contains the snake SVGs. Refresh the profile.

The avatar is loaded from `https://github.com/gowripriya521.png`, so your own GitHub profile image appears automatically.

The dashboard/header and footer SVGs contain animated effects. GitHub README supports some animated images but does not support a full interactive website or arbitrary CSS/JavaScript transitions. Stats and streak cards come from external services and may be temporarily unavailable. Snake activity depends on your GitHub contribution calendar. Do not upload API keys or `.env` files.
